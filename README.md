# Africore Mailing WebUI

Customized Stalwart WebUI for **Africore Mailing**.

## Production bundle

- `release/webui.zip` — current deployable Stalwart Web Application bundle.
- `release/webui-africore-mailing-v1.0.12-stalwart-0.16.24.zip` — favicon-fixed versioned bundle.
- `source/africore-mailing-source-acb7b63.zip` — corresponding source archive.
- `release/SHA256SUMS` — integrity hashes.

The customization applies Africore branding, burgundy UI tokens, an Africore favicon, removes Enterprise trial/activation promotions, and provides a Community dashboard that only uses management/JMAP data available to the current account. It does not unlock or bypass Enterprise-only server features.

Rollback URL:

`https://github.com/stalwartlabs/webui/releases/latest/download/webui.zip`
